本書で使う数学

Web補助資料 A ／ 多鹿 智哉

本書では数学の使用を最小限に抑えているが，それでも等式変形・関数・微分・最大化問題などは随所で登場する．ここでは本書を読み進める上で必要となる範囲の数学を簡単にまとめる．高校までの数学に自信がある読者は飛ばして構わない．

等式変形

等式（$=$で結ばれた式）に対してできる操作は次の3つに集約される．第一に，両辺に同じ数を足しても等式は成立したままである．たとえば$x = a$ならば$x + b = a + b$である．第二に，両辺に同じ数をかけても等式はそのままで，$x = a$ならば$b x = b a$となる．第三に，割る数が$0$でなければ両辺を同じ数で割ってもよい．つまり$a x = a b$かつ$a \neq 0$ならば$x = b$である．

等式を解く

変数を$x$としたとき，$x = (x \text{を含まない式})$という形にすることを 「等式を$x$について解く」 と呼ぶ．次の例で具体的に見てみよう．

例：$bx + 1 = 3$を$x$について解く．

\[ \begin{aligned} & b x + 1 = 3 \\ \Rightarrow{} & b x + 1 + (-1) = 3 + (-1) && \text{(両辺に$-1$を足す)} \\ \Rightarrow{} & b x = 2 && \text{(計算する)} \\ \Rightarrow{} & \begin{cases} x = \dfrac{2}{b} & (\text{もし$b \neq 0$なら}) \\ \text{解なし} & (\text{もし$b = 0$なら}) \end{cases} \end{aligned} \]

このように両辺に同じ操作を繰り返して，$x$を片側に「孤立」させるのが等式を解くという作業である．

式変形の道具

くくる

$a x - b x$という式があるとき，共通因数$x$を抜き出して$a x - b x = (a - b) x$と書ける．これを 「$x$でくくる」 という．

分数の和（通分）

$\dfrac{a}{b} + \dfrac{c}{d}$は分母を揃（そろ）えてから足す．$b, d \neq 0$なので$\dfrac{a}{b} = \dfrac{a}{b} \times \dfrac{d}{d}$，$\dfrac{c}{d} = \dfrac{c}{d} \times \dfrac{b}{b}$と書き直せて，

\[ \frac{a}{b} + \frac{c}{d} = \frac{a d}{b d} + \frac{b c}{b d} = \frac{a d + b c}{b d} \]

と計算できる．このように分母を揃える作業を 「通分」 という．

分数分の分数

$\dfrac{a}{c/d}$のように分数の中に分数が入る式は，分母分子に同じ数（ここでは$d$）をかけて簡単にする：

\[ \frac{a}{c/d} = \frac{a \times d}{(c/d) \times d} = \frac{a d}{c} \]

関数

入力を出力に割り当てる仕組みを 関数 と呼び，関数には名前（多くは$f$や$g$）をつける．たとえば$f(x) = 2 x + 1$という関数では，名前は$f$，入力は$x$，出力は$f(x)$（関数の値とも呼ぶ）である．数学的な式に限らず，現実のものを関数とみなすこともできる．たとえば自動販売（はんばい）機は，押したボタンを入力，出てくる飲み物を出力とする関数である．また入力する変数が複数あっても考え方は同じで，たとえば$u(x, y) = x \times y$は$x$と$y$という二つの入力に$x \times y$という出力を割り当てる関数である．

微分

関数$f$の 平均の傾き とは，$x$を$h$だけ増やしたときに$f(x)$がその何倍増えるかを表す数値である．

\[ \frac{f(x + h) - f(x)}{h} \]

この$h$をどんどん小さくしていくと，平均の傾きの値は接線の傾きに近づく．この極限を取って得られる値を，$x$における$f$の 微分 といい，記号で$f'(x)$と書く．

$h$が小さくなると接線の傾きに近づく（動画）

つまり 微分する とは 接線の傾きを求める 作業である．

近似式としての微分

本書の本文で微分が出てくるとき，接線の傾きという形で使われることはほとんどない．代わりに次の形が繰り返し登場する．

\[ f(x + h) \approx f(x) + f'(x) \times h \]

これは上の定義を書き直しただけである記号$\approx$は「だいたい等しい」という意味である．．$h$が小さいとき$\dfrac{f(x + h) - f(x)}{h}$は$f'(x)$にほぼ等しいのだから，その両辺に$h$をかければ$f(x + h) - f(x) \approx f'(x) \times h$となり，$f(x)$を右辺に移せばこの式になる．

言葉で言えば，$x$をほんの少し（$h$だけ）増やすと，$f$の値は1単位あたり$f'(x)$のペースで増える，ということである．「接線の傾き」と「1単位あたりのペース」は，同じ$f'(x)$を別の側から見たものである．グラフの上で見ているときは傾き，増える量を計算しているときはペースだと思えばよい．

ただしこれは等号ではなく近似である．$h$が大きくなればそれだけ誤差も大きくなる．本文で「ほんの少し増やすと」という言い方が繰り返されるのはこのためである．

傾きを求めると何が嬉しいのか．それは 増加局面か減少局面かが分かる ことである．$f'(x) \gt 0$なら$x$を少し増やすと$f$の値は増え，$f'(x) \lt 0$なら$x$を少し増やすと$f$の値は減る．この性質は後の最大化問題の節で本質的に使う．

微分の公式

以下では微分の計算のための公式を紹介する．

微分の公式 1（定数と一次関数）

  • $f(x) = a$（定数）ならば$f'(x) = 0$．定数なら変数がいくら変化しても関数の変化量は0である．
  • $f(x) = a x$ならば$f'(x) = a$．これは一次関数の傾きが$a$であることからわかる．

    • 微分の公式 2（べき乗）

    一般に，$f(x) = x^a$ならば$f'(x) = a x^{a-1}$である．

    なぜそうなるかを$f(x) = x^2 = \textcolor{blue}{x} \times \textcolor{red}{x}$で考えてみる．つまり，$x$を$\textcolor{blue}{x}$と$ \textcolor{red}{x}$に分けて考えそれぞれが独立に増加するとどうなるかというストーリーで考えてみる．

    1. まず$\textcolor{red}{x}$だけを変数とみなせば，もう一方の$\textcolor{blue}{x}$は係数になるので傾きは$\textcolor{blue}{x}$である．
    2. つまり$\textcolor{red}{x}$が$h$増えれば$f$は$\textcolor{blue}{x} \times h$増える．
    3. 逆に$\textcolor{blue}{x}$だけを変数とみなせば，傾きは$\textcolor{red}{x}$で，$\textcolor{blue}{x}$が$h$増えれば$f$は$\textcolor{red}{x} \times h$増える．
    4. 実際には$x$が$h$増えると$\textcolor{red}{x}$も$\textcolor{blue}{x}$も同時に$h$増えるので，$f$は合計で$\textcolor{blue}{x} \times h + \textcolor{red}{x} \times h = 2 x \times h$だけ増える正確にはこれに「両方が同時に動いたぶん」である$h \times h$が加わる．ただし$h$が小さいときこの部分は無視できる．$x = 3$，$h = 0.1$なら，$2 x \times h = 0.6$に対して$h \times h = 0.01$である．．
    5. これは「$x$が$h$増えると$f$は$2x$倍だけ増える」ことを意味し，微分は$2x$（$= 2 x^{2-1}$）となる．

    同じ話が$x^3$でも$x^a$でもできる．$x^3 = x \times x \times x$なら3つに分けて1つずつ動かすことになる．動かす場所は3通りあり，どれを動かしても増える分は「止めてある残り2つの積（せき）」である$x^2$に$h$を掛けたものなので，合計で$3 x^2 \times h$だけ増える．一般に$x^a$なら$a$個に分けることになり，動かす場所は$a$通り，どれを動かしても増える分は残り$a-1$個の積$x^{a-1}$に$h$を掛けたものだから，合計は$a x^{a-1} \times h$である．公式の$a$は分けた個数，$a-1$は止めてある残りの個数だと読めるこの数え方ができるのは$a$が正の整数のときである．$x^{1/2}$や$x^{-3}$のような場合は，公式のほうを認めてもらうことになる．．

    べき乗の微分

    次の関数の微分を求めよ．

    1. $f(x) = x^4$
    2. $f(x) = x^{1/2}$
    3. $f(x) = x^{-3}$

    $f(x) = x^a$ならば$f'(x) = a x^{a-1}$を当てはめれば良い．

    1. $f'(x) = 4 x^3$
    2. $f'(x) = \dfrac{1}{2} x^{-1/2} = \dfrac{1}{2 \sqrt{x}}$
    3. $f'(x) = -3 x^{-4} = -\dfrac{3}{x^4}$

    微分の公式 3（定数倍と和）

    定数倍については，$f(x) = a \, g(x)$ならば$f'(x) = a \, g'(x)$である．和については，$f(x) = h(x) + g(x)$ならば$f'(x) = h'(x) + g'(x)$である．

    定数倍と和の微分

    次の関数の微分を求めよ（$a$は定数とする）．

    1. $f(x) = 3 x^2$
    2. $f(x) = 2 x^3 + 3 a$
    1. $f'(x) = 3 \times 2 x = 6 x$
    2. $2 x^3$の微分は$6 x^2$，$3 a$は定数なので微分は$0$．したがって$f'(x) = 6 x^2$．

    「限界〜」と微分

    本文には限界費用・限界生産物・限界効用・限界代替率という言葉が出てくる．これらはすべて，前節の近似式を経済の言葉で言い直したものである「限界〜」は英語のmarginalの訳語である．marginは紙の余白やページのふちを指す語で，「いま立っているところのすぐ隣まで動かす」という意味あいで使われている．．

    たとえば総費用関数$C$の微分を限界費用と呼び，本文では$\MC(q)$と書く．前節の近似式にそのまま当てはめれば

    \[ C(q + h) \approx C(q) + \MC(q) \times h \]

    となる．いま$q$個作っているところから$h$個だけ追加で作ると，費用は1個あたり$\MC(q)$のペースで増える，ということである．

    他の「限界〜」も作り方は同じで，何を何で微分したかが違うだけである．

    • 限界費用$\MC(q)$：総費用$C(q)$の微分．つまり$\MC(q) = C'(q)$である．
    • 限界生産物$\MP_L$：生産量を労働量$L$で微分したもの．人を1人増やしたときに増える生産量．
    • 限界効用$\MU_x$：効用$u(q_x, q_y)$を財$x$の消費量で微分したもの．

    なお，限界生産物と限界費用には変数が2つあるので，これらは正確には後に紹介する偏微分にあたる．

    記号は章によって使い分けている．限界費用は$\MC(q)$と書くこともあれば$C'(q)$と書くこともあり，どちらも同じものである．第9章の公共財の設計の節に出てくる$v'_{\text{ア}}(q)$も，アダムの効用$v_{\text{ア}}$の微分なので限界効用である．

    本文の議論との関係についても説明する．利潤や効用が最大になっている条件を求めるとき，本文は微分して$0$と置くという計算をせず，「いまの状態から少しだけ動かして改善（かいぜん）できるなら，そこはベストではない」という形で議論を進める．そこで「少しだけ動かしたときにどれだけ変わるか」を与えるのが限界費用や限界効用である．次節の一階の条件は，この議論を微分の記号で書いたものにあたる．

    最大化問題

    関数$f(p)$の$p$に関する 最大化解 $p^*$とは，どんな$p$に対しても$f(p^*) \geq f(p)$が成立するような$p^*$のことである．このときの$f(p^*)$を 最大値 と呼ぶ．

    これらを記号で表すと，最大値は

    \[ \max_{p} f(p) = f(p^*), \]

    最大化解は

    \[ \arg\max_{p} f(p) = p^* \]

    と書く「$\arg\max$」は「argument of the maximum（最大値を達成する引数）」の略である．最大値$\max_p f(p)$は関数の出力の値（数）であるのに対し，最大化解$\arg\max_p f(p)$は入力の値（$p$）である，という違いに注意．．たとえば$f(p) = -(p-2)^2 + 5$という関数を考えると，$-(p-2)^2 \leq 0$で等号は$p = 2$のときだから，

    \[ \max_{p} f(p) = 5, \qquad \arg\max_{p} f(p) = 2 \]

    となる$f(p^*) = f(p^{**})$となる別の点$p^{**}$がある場合のように，最大化解は一般に複数存在しうる．したがって厳密には$\arg\max_p f(p)$は最大値を達成する$p$の集合$\{p \mid f(p) = \max_q f(q)\}$を表すと考えるべきだが，本書では混乱を避けるため主に最大化解が一意に定まる場合を扱う．．

    同じ$\max$の記号は，関数だけでなく 有限個の数のうち最大のもの を表すのにも使う．たとえば

    \[ \max\{3, 7, 5\} = 7 \]

    のように書く．

    最小化問題についても同様に，最小値 $\min_p f(p)$と 最小化解 $\arg\min_p f(p)$が定義され，数の集合に対しても$\min\{3, 7, 5\} = 3$のように使う．$f$を最小化することは$-f$を最大化することに等しいので，以下の最大化のための道具立て（一階の条件など）はそのまま最小化にも使える．

    最大化解の必要条件（一階の条件）

    $p^*$が最大化解ならば$f'(p^*) = 0$．

    （理由）$f'(p^*) \gt 0$なら$p^*$から$p$を少し増やせば$f$の値は大きくなる．$f'(p^*) \lt 0$なら$p^*$から$p$を少し減らせば$f$の値は大きくなる．どちらのケースでも$f(p^*)$は最大値になっていない．したがって最大化解では$f'(p^*) = 0$でなければならない．

    最大化解を求める手順

    最大値が存在し，関数$f$がいたるところで微分でき，$p$に制約がない場合は，まず$f'(p) = 0$となる$p$をすべて探し，そのなかで$f(p)$の値が一番大きいものが最大化解である．

    最大化問題の例

    $f(p) = -p^2 + 2 p$の最大化解と最大値を求めよ．

    微分すると$f'(p) = -2 p + 2$．$f'(p) = 0$となるのは$p = 1$．このとき$f(1) = -1 + 2 = 1$．したがって最大化解は$p^* = 1$，最大値は$1$．

    微分では求められない場合

    上の手順には「最大値が存在し，関数$f$がいたるところで微分でき，$p$に制約がない場合は」という但（ただ）し書きが付いている．この条件（じょうけん）が外れると，$f'(p) = 0$を解くやり方は使えない．本文の練習問題にもそういう問題が混（ま）じっているので，起こりやすい3つを挙げておく．

    • 選べる範囲に制限があるとき：たとえば$0 \leqq q \leqq 100$のように範囲が決まっていると，範囲の端（はし）が答えになることがある．端では「少し増やす」か「少し減らす」かの片方しかできないので，改善できるかどうかを片側だけで確かめることになる．$f'(q) = 0$となる$q$に加えて，両端での$f$の値も比較（ひかく）する必要があるこのように範囲の端が答えになる場合を端点解（たんてんかい）と呼ぶ．．
    • 傾きが$0$にならないとき：$f(q) = (p - 4) q$のような一次関数では，傾きは$p - 4$で一定である．$p > 4$ならどこまでも増え続けるので範囲の右端が，$p < 4$なら左端が答えになる．$p = 4$ならどの$q$でも値が同じで，最大化解は1つに定まらない．
    • 微分できない点があるとき：グラフに尖（とが）っている点があると，その点では複数の接線が引けてしまう．この場合は接線の傾きが一つに決まらないので微分できない．尖っている点も候補に入れて値を比べる必要がある．

    いずれの場合も，「少し動かして改善できるならベストではない」という考え方そのものは使（つか）える．使えなくなるのは$f'(p) = 0$という計算（けいさん）のほうである．

    偏微分

    偏微分（へんびぶん） とは，関数に複数の変数があるときに，特定の一つの変数についてのみ微分する操作である．他の変数は定数として扱う．やること自体は通常の微分と同じである．

    関数$f(x, y)$を$x$で偏微分したものを$\pd{f}{x}$と書く．本文はこの記号を使わず，効用$u(q_x, q_y)$を財$x$の消費量で偏微分したものを限界効用$\MU_x$と呼んでいる．中身は同じもので，$\MU_x = \pd{u}{q_x}$である．他の教科書に進むときのためにここに記号を挙（あ）げておく．

    通常の微分と同じ発想で，$f(x, y)$について，例えば$x$を$h$だけ増やすと \[f(x+h, y)\approx f(x, y)+\pd{f}{x}(x,y) h\] が，$h$が小さときに成り立つ．要するに，$f$は$x$を増やすと$\pd{f}{x}(x,y)$に比例して増えていくということである．

    偏微分の例

    例 1：$f(x, y) = x^2 + y^3$のとき．$x$で偏微分するときは$y$を定数とみなすので，$y^3$の項の微分は$0$となり$\pd{f}{x} = 2 x$．逆に$y$で偏微分するときは$x$を定数とみなし，$x^2$の項の微分が$0$になるので$\pd{f}{y} = 3 y^2$．

    例 2：$f(x, y) = x^2 y^4$のとき．$y$で偏微分するときは$x^2$は$y$に関係しないので定数扱いとなり，$y^4$の微分が$4 y^3$であることから$\pd{f}{y} = 4 x^2 y^3$．同様にして$\pd{f}{x} = 2 x y^4$．
